玻璃雨珠 · 独立版

这个页面的背景只靠一行 script 标签就有了

引入方式（放在页面 body 结束标签之前）：

<script src="/js/glass-rain.js"></script>

想改雨势或资源目录，就在它之前加一段配置：

<script>
  window.GLASS_RAIN = {
    weather: 'rain',    // rain / drizzle / sunny / storm / fallout
    zIndex: -1,         // 看不到就改成 0 或 1
    opacity: 1
  };
</script>

背景是固定层，不会挡住点击；上面的卡片就是普通页面内容。
